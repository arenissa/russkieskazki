# Сказочная вертушка

Иллюстрированный конструктор сказок для 5 класса: герой, злодей, волшебный предмет, помощник и загадочный встречный. Разработка Светланы (arenissa).

## Как открыть
Откройте `index.html` в браузере. Сервер и установка библиотек не нужны. Для передачи одним файлом используйте `skazochnaya-vertushka-offline.html`: внутри есть все изображения и код.

## Возможности
- Имя сказочника; по желанию — собственное имя в роли главного героя.
- Две попытки на группу, закрепление лент и выбор результата.
- Светлая и тёмная темы.
- Сохранение листа в PNG и печать на A4.
- Подписи, сведения о персонажах, ссылки на народные источники.
- Имя, попытки, настройки и замысел хранятся локально в браузере. Их очистка или другой браузер начинает отдельную работу.

## Материалы
В `materials/` находятся яркие листы для текста сказки, памятка, цветные карты A3/A4, легенда и картинки для проектора.

## GitHub Pages
Этот проект — статический сайт. После загрузки файлов в корень репозитория включите GitHub Pages для ветки main и папки / (root) в настройках Pages. Содержимое папки проекта загружается целиком, вместе с images/ и materials/.

## Как это устроено
`game.js` — правила; `data.js` — картотека; `app.js` — интерфейс и экспорт; `style.css` — оформление; `images/` — лёгкие версии картинок для лент и оригиналы для печати.

Иллюстрации созданы генератором изображений. Роли и география карты предложены для авторских сказок; народные источники указаны в карточках. Проект не требует платных API или внешних шрифтов для игры. Ссылки на тексты сказок открываются в интернете.
